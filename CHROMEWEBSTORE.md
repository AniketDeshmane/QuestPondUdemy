# Chrome Web Store Listing — QuestPond Udemy-Style UI Beautifier

> Last Updated: 2026-08-22

## Store Listing Metadata

**Extension Name**
QuestPond Udemy-Style UI Beautifier

**Short Description**
Transforms QuestPond's course dashboard and video player into a modern, clean Udemy-style learning platform.

**Detailed Description**
Elevate your QuestPond learning journey with a sleek, modern, and highly intuitive Udemy-style interface.

QuestPond Beautifier upgrades the default course catalog and video player into an elegant, distraction-free environment packed with productivity tools.

✨ KEY FEATURES:

1. Modern "My Learning" Course Dashboard:
- Responsive 4-column course card grid replacing old accordion bars.
- Dynamic tech-themed artwork (Angular, .NET, C#, Azure, SQL, Docker, React, AI/ML, and more).
- Star rating indicators, lesson count badges, and Udemy purple progress bars.
- Interactive modal drawer to preview lectures and direct links.
- Instant live search and category filter tabs.
- Dedicated Interview Mode switch.

2. Cinema Theater Video Player:
- Dark theater mode background around video lectures.
- Course navigation header with quick return to curriculum.
- Udemy purple "Complete and Continue" action button.
- Sub-tabs for Overview, Notes, Announcements, and Reviews.
- Enhanced sidebar curriculum with lesson durations (e.g. ⏱ 71:26) and section aggregate stats.

3. Extension Popup & Preferences:
- Quick one-click toggles for UI customization.
- Instant tab reloader.

🔒 PRIVACY & SECURITY:
QuestPond Beautifier is 100% client-side. It does NOT collect, transmit, or store any personal data, passwords, or browsing history. All styling and DOM transformations occur locally in your browser.

**Category**
Productivity / Developer Tools

**Single Purpose**
Redesigns QuestPond's course dashboard and video player into a modern Udemy-style interface with progress tracking and search.

English

## Permissions Justification

| Permission | Type | Justification |
|---|---|---|
| `storage` | permissions | Saves user preferences locally (such as dark mode toggle and UI enablement). |
| `activeTab` | permissions | Allows the popup to reload the active QuestPond tab when settings change. |
| `*://questpond.teachable.com/*` | host_permissions | Injects the Udemy stylesheet and DOM layout improvements on QuestPond course pages. |
| `*://www.questpond.com/*` | host_permissions | Injects styling and improvements when navigating QuestPond domains. |
